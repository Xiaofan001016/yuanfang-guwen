## OpenAI 导入方式

### 方式一：上传 JSONL 到 OpenAI Files API（推荐）

```bash
curl https://api.openai.com/v1/files \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -F purpose=file \
  -F file=@law_knowledge_base.jsonl
```

### 方式二：ChatGPT 知识库直接上传

在 ChatGPT → 知识库 → 上传文件，选择本仓库 `laws/` 目录下的 `.md` 文件即可。

### 方式三：智能体通过 HTTP 实时拉取

在智能体的 system prompt 中告知：需要法条原文时，直接 GET 上述 raw 链接。
